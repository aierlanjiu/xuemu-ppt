03

Workflow

  1. Install the skill to your agent environment.
  2. Invoke the skill by saying: "用 xuemu-ppt 做一份杂志风PPT" or "用 CFD 水晶风格做一份技术发布会deck".
  3. The agent generates HTML/MP4 presentations using Motion.js.
